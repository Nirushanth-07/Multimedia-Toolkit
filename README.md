## Voice Recorder
A simple command-line audio recording tool that captures input from your microphone and saves it as a high-quality `.wav` file.

### How to Use
1. Run the script: `python voice_recorder.py`
2. When prompted, enter the recording duration in minutes.
3. The file will be saved as `my_recording.wav` in the project directory.

